# COMO UTILIZAR O GITHUB

O **GitHub** é uma plataforma utilizada por desenvolvedores para armazenar, compartilhar e organizar projetos de programação.

## 1. Como criar uma conta

1. Acesse o site: https://github.com
2. Clique em **SIGN UP** (Cadastrar).
3. Informe seu e-mail.
4. Crie uma senha.
5. Finalize o cadastro e confirme sua conta.

## 2. Criando um repositório

O **repositório** é o espaço onde seus arquivos e códigos ficam armazenados.

1. Entre na sua conta.
2. Clique no botão **New**.
3. Digite o nome do projeto.
4. Adicione uma descrição.
5. Escolha se será público ou privado.
6. Clique em **Create Repository**.

## 3. Adicionando arquivos ao projeto

1. Entre no repositório criado.
2. Clique em **Add File**.
3. Selecione **Upload Files**.
4. Escolha os arquivos do seu computador.
5. Aguarde o carregamento.
6. Clique em **Commit Changes**.

## 4. O que significa Commit?

**Commit** é o registro de uma alteração realizada no projeto.

Exemplos de alterações:

- Adicionar uma página HTML.
- Corrigir um erro no código.
- Alterar o design do site.
- Adicionar uma nova funcionalidade.

## 5. Como compartilhar o projeto

1. Abra seu repositório.
2. Clique em **Code**.
3. Copie o endereço do projeto.
4. Compartilhe o link com professores, colegas ou recrutadores.
